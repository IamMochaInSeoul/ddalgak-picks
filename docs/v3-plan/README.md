# 딸깍픽스 v3 — 신규 기획 문서 세트

> **작성일:** 2026-04-27 (인물 클러스터링 기능 추가 갱신)
> **상태:** 기획 확정 (개발 착수 전)
> **목적:** 기존 v0.2.x 위에서, "스튜디오 1000장+ 셀렉" 시장에 정조준한 유료 서비스로 재정의

## 최신 갱신 사항 (2026-04-27 — 사용자 피드백 4차 반영)

### 1차 추가 — 인물 자동 클러스터링 + 주인공 선택 (F18)
- 아이폰 사진앱 "인물" 탭처럼 같은 사람을 자동으로 묶고, 사용자가 주인공을 직접 선택
- AND/OR 모드 사용자 토글 / 비주인공 컷 보장 옵션 / 카메라 응시 추정
- TECH_SPEC §3.7~§3.9 신규 / §4 파이프라인에 인물 단계 2개

### 2차 추가 — 결제 허들 최소화 + 정확도 보장 + 파일명 가림 + 모바일 미루기 + 토스식 UX (이번 라운드)
- **가격 재설계:** 1회권 ₩9,900 → ₩4,900 (재추출 무한, 다운로드 1회) + 패키지 ₩15,000 (모두 무한, 90일)
- **광고 정책 재정의:** 모든 화면 노출하되 비침해 디자인 강제 (분석 결과·결제 의사결정·인물 카드 위 절대 X)
- **정확도 게이트 신설 (TECH_SPEC §14.0):** B급 recall ≥ 92% / FPR ≤ 8% / F1 ≥ 0.85 / 인물 ≥ 90%/95% — 미달 시 출시 보류
- **파일명 가림 (F19):** UI는 가명(`DDP-만삭-001`), 무료 ZIP도 가명, 결제 ZIP만 원본 파일명 보존 → 우회 방지 + 결제 동기 강화
- **모바일 v3.1+로 미루기:** MVP는 PC 웹 전용, 모바일 접속 시 "곧 지원, 알림 신청" 안내
- **토스식 UX 강제 사양 (F20, PRD §6.B + TECH_SPEC §17):** 한 화면 한 결정, 메인 CTA 1개, 마이크로카피 5원칙, ESLint 룰로 위반 자동 감지

### 누적 변경
- PRD: 차별점 5→7, 기능 P0 14개 → 20개 (F18·F19·F20·F21·F22·F23)
- TECH_SPEC: §3.7~3.9, §7.6, §8.0, §14.0(라벨링 협업 포함), §15.3(계정·역할 포함), §16(Drive 연동), §17 신규 추가
- 첫 스프린트 일정 3~4주 (모바일 빠지고 라벨링/어드민/Drive 추가 상쇄)
- PR 분리 13 → 17개 (파일명·UX 강제·정확도·라벨링 협업·어드민·Drive 모두 포함)

### 3차 추가 — 결제 단계화 + Supabase 확정 + 어드민 페이지 (사용자 답변 반영)
- **결제 PG 사업자 미보유 대응:** PR 8 결제 모듈은 포트원 sandbox로 완전히 개발 → 출시 직전 사업자등록 + 가맹등록 후 환경변수만 전환 (TECH_SPEC §8.0)
- **백엔드 Supabase 확정:** Edge Functions + Postgres + Auth + Storage 통합. 어드민 페이지·결제·텔레메트리 모두 한 플랫폼
- **어드민 페이지 (F21) 신규 P0:** 대시보드·결제 관리·쿠폰 발급·정확도 모니터링·비상 토글 8개 영역. MVP는 핵심 6개로 출시 후 점진 확장 (TECH_SPEC §15.3)

### 4차 추가 — 라벨링 협업 + 계정·권한 관리 강화
- **다중 라벨러 협업 (F22) 신규 P0:** 운영자가 동료들에게 초대 링크 발송 → 각자 별도 계정으로 라벨링 → 합의 알고리즘(과반 다수결)으로 정답지 추출. 분쟁 사진은 어드민이 1클릭 결정. 블라인드 모드(다른 라벨러 결정 비공개)·키보드 단축키·signed URL로 사진 보호
- **계정·권한 관리 (F21.3 확장):** 어드민/라벨러/회원/게스트 4개 역할. 계정 목록·역할 변경·비밀번호 리셋·활동 로그·감사 로그 / 비회원 결제 이메일 디렉터리(v3.2 회원 가입 시 자동 병합)

### 5차 추가 — Google Drive 폴더 연동 (F23)
- **신규 P0:** 스튜디오가 Drive로 사진 보내는 시나리오 정조준. PC 다운로드 없이 Drive 폴더 직접 분석
- **단계화 다운로드 전략:** 분석 단계는 썸네일(800px)만 받음 → 결제 후 선별된 사진만 원본 다운로드 (대역폭·시간 1/8로 절감)
- **무료/유료 차별화 강화:** 무료는 썸네일+워터마크 ZIP만, 클린 ZIP은 결제만 가능 → 결제 동기 명확
- **기존 v0.2.x AlbumContainer의 OAuth/Picker/Drive API 코드 재활용** — `VITE_GOOGLE_CLIENT_ID`/`VITE_GOOGLE_API_KEY` 그대로
- **PR 분리 16→17개:** F23 Drive 연동 PR 16 신설, 통합·출시는 PR 17로 밀림

## 이 폴더는 무엇인가

기존 `src/`, `PROJECT_STATUS.md`는 **그대로 보존**됩니다. 이 폴더는 **새 버전(v3)을 위한 기획·기술 명세 세트**이며, Claude Code가 이 두 문서만 읽고 바로 다음 스프린트에 착수할 수 있도록 작성됐습니다.
